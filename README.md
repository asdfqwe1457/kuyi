阶梯拼团的设计

WANLSHOP的阶梯拼团功能支持"自定义人数拼团、直购、不同阶梯人数不同优惠金额拼团"。传统拼团是"固定人数成团，享受固定优惠"。阶梯拼团则更进一步：不同人数对应不同优惠金额。例如：2人拼团减10元，3人拼团减20元，5人拼团减40元。

阶梯拼团的价值在于：激励用户主动传播、提升成团率、增加客单价。用户为了获得更大优惠，会主动邀请更多好友。直购模式则给用户更多选择：急于购买的用户选择直购，愿意等待的用户选择拼团。

多类型优惠券

WANLSHOP支持"发布多种类型优惠券：打折、减满、包邮券"。优惠券是电商最常用的促销工具：

打折券：按比例优惠，如9折

满减券：满一定金额减一定金额，如满200减20

包邮券：免除运费，适合低客单价商品

优惠券的价值在于：引导用户下单、提升客单价、清理库存。系统需要支持优惠券的创建、发放、领取、使用、过期等全生命周期管理。

我的钱包

WANLSHOP提供"我的钱包"功能：充值、提现、账单明细。钱包功能的价值在于：提升用户资金留存、方便用户消费、支持分销提现。钱包涉及资金安全，技术实现需要严谨：账变记录、并发场景下的数据一致性、提现审核。

财务管理

系统提供"后台和商家后台对账单、支付提现明细"。财务管理是多商户平台的核心模块，涉及：订单对账、佣金结算、提现审核、财务报表。
